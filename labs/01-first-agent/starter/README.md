# Starter project

Follow [the lab guide](../README.md) while this project remains in the course repository. If copied elsewhere, retain the course path separately. The five lesson files explain planning, instructions, tests, implementation, and completion.

Run `npm ci`, `npm run check:setup`, `npm run typecheck`, and `npm run build` from this directory after planning. `npm test` runs Vitest once. `npm run demo -- --scenario happy --issue ISSUE-001` runs the compiled CLI.

This is deliberately unfinished: write your own tests before implementing src/agent.ts. NOT_IMPLEMENTED and no-test outcomes are expected until you work through the lessons.
